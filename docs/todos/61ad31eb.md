## Context

The project currently uses npm (`package-lock.json`, npm/npx commands in `package.json`, `justfile`, and README). A temp migration check showed PNPM works, but PNPM 11 requires approving the `esbuild@0.21.5` install/build script.

Verification from temp checkout:

- `pnpm import` generated `pnpm-lock.yaml`
- `pnpm install` initially failed with `ERR_PNPM_IGNORED_BUILDS` for `esbuild@0.21.5`
- `pnpm approve-builds --all` generated `pnpm-workspace.yaml` with:

  ```yaml
  allowBuilds:
    esbuild: true
  ```

- After approval, `pnpm install --frozen-lockfile`, `pnpm test`, and `pnpm build` passed
- Test result observed: 13 files / 114 tests passing

## Proposed work

1. Replace npm lockfile with PNPM lockfile:
   - Remove `package-lock.json`
   - Add generated `pnpm-lock.yaml`

2. Pin package manager in `package.json`, for example:

   ```json
   "packageManager": "pnpm@11.1.1"
   ```

3. Commit PNPM build approval:

   ```yaml
   # pnpm-workspace.yaml
   allowBuilds:
     esbuild: true
   ```

4. Update project commands:
   - `package.json`: change `"smoke": "npm run build && bash scripts/smoke-test.sh"` to PNPM equivalent
   - `justfile`:
     - `npm install --silent && npx tsc` -> `pnpm install --silent && pnpm exec tsc`
     - `npx vitest run` -> `pnpm exec vitest run`
   - README install/smoke docs:
     - `npm install` -> `pnpm install`
     - `npm run build` -> `pnpm build`
     - `npm run smoke` -> `pnpm smoke`

5. Consider first-class PNPM support inside sandbox policies:
   - Existing profiles allow `~/.npm` but not PNPM's default store/cache paths
   - If Claude is expected to run PNPM inside the sandbox, add relevant PNPM store/cache paths to interactive/build/bootstrap profile filesystem allowances and update tests/docs accordingly

## Acceptance criteria

- Repo uses `pnpm-lock.yaml` and no longer relies on `package-lock.json`
- Project docs and just recipes use PNPM commands
- `pnpm install --frozen-lockfile` succeeds from a clean checkout
- `pnpm test` passes
- `pnpm build` passes
- Decision made/documented on whether sandbox policies should explicitly support PNPM cache/store paths
